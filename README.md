# 채록 (Chaerok) · Roll20 로그 백업 도우미

Roll20 Chat Archive를 붙여넣기만 하면 정리해서 **티스토리에 바로 올릴 수 있는 HTML**과
**깔끔한 PDF**로 만들어주는 정적 웹앱입니다. 서버나 빌드 과정 없이 순수 HTML/CSS/JS로
동작하며, GitHub Pages로 바로 배포할 수 있습니다.

## 왜 다시 만들었나

기존 버전(`dedvil.github.io/roll20-log-editor`)은 로그 입력창이 `<textarea>`였기 때문에
Roll20 Chat Archive에서 복사한 서식 있는 HTML을 붙여넣어도 **일반 텍스트로만 저장되어
화자·서식·이미지 정보가 모두 사라지는 문제**가 있었습니다. 이번 버전은 입력창을
`contenteditable`로 바꾸고, Roll20의 실제 채팅 마크업(`.message`, `.by`, `.whisper`,
`.rollresult` 등)을 인식하는 파서를 새로 작성해 이 문제를 해결했습니다.

## 주요 기능

- **붙여넣기 한 번으로 백업** — Chat Archive를 통째로 복사해 붙여넣으면 즉시 자동 인식·정리
- **저장한 HTML + 이미지 폴더 업로드** — "웹페이지, 전부"로 저장한 경우도 지원 (아바타 이미지 자동 연결)
- **`this message is hidden` 자동 삭제**
- **로그 두배 렌더링 오류 자동 해결** — 전체 로그가 통째로 두 번 붙여넣어진 경우와, 메시지가
  연속으로 중복 렌더된 경우를 모두 감지해 제거
- **점삼육(말줄임표) 및 부호 자동 교정** — `..`/`......` 등을 `...` 또는 `......`으로 표준화,
  물결표·중복 느낌표/물음표·불필요한 공백 정리
- **배경색 자동 통일** — 메시지별로 제각각인 배경색을 제거하고 하나의 테마로 통일
  (다이스 아이콘 등 이미지 배경은 보존)
- **캐릭터 관리** — 화자 목록/등장 횟수 확인, 이름 클릭으로 이름변경·병합, 선택 캐릭터
  로그 일괄 삭제
- **상세 통계** — 전체·캐릭터별 메시지 수, 글자수(공백 포함/제외), 타입별 집계
- **검색** — 대사·화자 검색 및 하이라이트, 타입별 필터 칩(대사/감정/귓속말/판정/시스템/이미지)
- **메시지 편집/삭제** — 더블클릭으로 본문 직접 수정, 메시지 단위 삭제, 실행 취소(undo)
- **내보내기**
  - 티스토리 HTML 클립보드 복사 / 파일 다운로드 (자체 `<style>` 포함, 붙여넣으면 바로 표시)
  - PDF 저장 (브라우저 인쇄 다이얼로그, 표지 페이지 지원)
  - TXT / JSON 백업 다운로드 및 JSON 복원
- **자동 저장** — 브라우저 `localStorage`에 자동 저장되어 실수로 탭을 닫아도 복구 가능

## 폴더 구조

```
index.html
css/
  style.css      앱 UI 스타일
  print.css      PDF(인쇄) 전용 스타일
js/
  utils.js       공용 헬퍼
  parser.js      Roll20 HTML / 텍스트 로그 파서
  cleaner.js     자동 정리(부호 교정, 중복 제거, 숨김 삭제)
  characters.js  캐릭터 추출·이름변경/병합·일괄삭제
  stats.js       통계 계산
  search.js      검색/하이라이트
  renderer.js    화면 렌더링
  exporter.js    티스토리 HTML / PDF / TXT / JSON 내보내기
  app.js         상태 관리 및 이벤트 와이어링
```

빌드 도구나 npm 의존성이 없습니다. `index.html`을 브라우저로 열거나 정적 파일 서버로
서빙하면 그대로 동작합니다.

## 로컬에서 열어보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

(파일을 더블클릭해 `file://`로 직접 열어도 대부분의 기능이 동작하지만, 클립보드 복사
등 일부 브라우저 API는 `http(s)://`에서 더 안정적으로 동작합니다.)

## GitHub Pages로 배포하기

1. 이 폴더의 내용을 저장소(`roll20-log-editor` 등) 루트에 그대로 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 배포 브랜치를 지정합니다.
3. `https://<사용자명>.github.io/<저장소명>/` 주소로 접속해 확인합니다.

## Roll20 채팅 로그 가져오는 방법

앱 상단의 **"가져오기 방법"** 버튼에서도 동일한 안내를 볼 수 있습니다.

1. Roll20 캠페인 페이지 → **[이 게임의 모든 채팅 내용 보기]** (또는 **[게임 > 내용 > 채팅 기록]**)
   → Chat Archive 화면에서 **[Show on One Page]** 클릭
2. **방법 1 (추천)**: 전체 선택(Ctrl/Cmd+A) → 복사(Ctrl/Cmd+C) → 이 앱의 붙여넣기 상자에
   붙여넣기(Ctrl/Cmd+V)
3. **방법 2 (이미지까지 보존)**: 브라우저의 "페이지를 다른 이름으로 저장 → 웹페이지, 전부"로
   저장한 뒤, 생성된 `.html` 파일과 `_files` 폴더를 이 앱에 업로드
