Roll20 채팅 로그 가져오기 방법

먼저 Roll20 캠페인 페이지의 [이 게임의 모든 채팅 내용 보기](또는 [게임 > 내용 > 채팅 기록])으로 들어가 Chat Archive 화면을 열고 [Show on One Page] 버튼을 눌러 한 페이지로 펼쳐주세요.

방법 1 · 복사 붙여넣기 (추천)

  1. Chat Archive 화면에서 전체 선택 Ctrl(⌘)+A → 복사 Ctrl(⌘)+C
  2. 이 페이지 왼쪽의 붙여넣기 상자에 Ctrl(⌘)+V

복사·붙여넣기 한 번이면 끝, 가장 빠른 방법이에요. 다만 플레이어 아바타 등 원본 서버에만 있는 일부 이미지는 원본이 사라지면 함께 사라져요.

방법 2 · 웹페이지 저장 (이미지까지 보존)

  1. Chat Archive 화면에서 브라우저 메뉴 [파일] → [페이지를 다른 이름으로 저장] → "웹페이지, 전부" 선택 후 저장
  2. 다운로드된 .html 파일과 함께 생성된 _files 폴더를 이 페이지의 "저장한 HTML 파일로 올리기"에 순서대로 업로드

이미지가 파일로 함께 저장되어 원본이 사라져도 보존이 확실해요. 다만 플레이어 아바타는 저장에 포함되지 않아 직접 올려야 해요.
